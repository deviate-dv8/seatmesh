- **oc-proxy** — explicit CPE OpenCode runner (`agents.runners.oc-proxy`); bare `opencode` stays unproxied
- **`sm pane resume`** — autodetect `ses_*` / resume id → inject or relaunch with keep-resume
- **OC-LIMIT reset** — one path: proxy restart → wait new IP → kill CPE OC → relaunch + CONTINUE
- **todo check bulk** — remaining open TASKS DIGEST-bulk'd to the seat (peer-bulk format)
- **`sm web`** — hub parity (`status` / `open` / `url`); `npm run web` → `:3190`
- **`sm config upgrade`** — step 1 is `npm install -g seatmesh@latest`, then `update`
- **`docs/patterns/`** — modular feature patterns (CLI / web / daemon tags)
