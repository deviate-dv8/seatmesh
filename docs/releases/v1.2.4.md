# seatmesh 1.2.4

Open agent kinds: providers emit `kindBase` / `kindExtensions`; meshes overlay
`agents.kinds`. **`oc-proxy` extends `opencode`** (same inject provider; CPE launch +
prove/satisfy/recovery). `type` is an open string validated against resolved kinds.

Also: hub act/card cutover, wave OC relaunch, Orca credit CONTINUE, cross-mesh inbox
restart when `TMUX_PANE` is foreign; oc-proxy→main sync workflow disabled.

## Custom CLI (e.g. Kimi) without forking

- **Launch:** `.sm/mesh.config.yaml` → `agents.kinds.kimi: { provider, launch }` + `switch … kimi`
- **Inject:** still needs an `AgentProvider` module (PR or upcoming **`.sm/providers/`** loader — see `TODO.md` P6.1)

npm i -g seatmesh@1.2.4
