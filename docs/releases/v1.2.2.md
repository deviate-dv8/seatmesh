# seatmesh 1.2.2

`npx seatmesh web up|down|restart|status|open|url` — operator hub lifecycle on `:3190`.

## Summary

- **`sm web up|down|restart`** — start/stop hub from a seatmesh checkout (`packages/web`; set `SEATMESH_WEB_ROOT` if needed)
- **`sm web status|open|url`** — parity with hub routes + daemon tips
- **`sm agent mds hosted|agent-self|agent <kind>`** — three markdown galleries (`.sm/mds` ↔ hub `/mds`, seat MDs, role POV)
- Hub `/mds` lists live `.sm/mds` files + show route
- OC-LIMIT V2 ops: supervisor 3×30s `/health` rescue; orphan stamp reclaim; `oc-credit` → atomic 4 CONTINUE (not CPE reboot)

## Install

```bash
npm i -g seatmesh@1.2.2
# or
npx seatmesh@1.2.2 web status
npx seatmesh@1.2.2 web up
```
