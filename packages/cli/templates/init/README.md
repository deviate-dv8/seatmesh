# .sm — seatmesh project config

Generated by `sm init` (or `npx seatmesh init`). The engine reads **only** files here (+ live
`mesh-agents.json` state).

| Path | Purpose |
|------|---------|
| `mesh.config.yaml` | Layout, daemon, connectivity, seat paths |
| `mesh-agents.json` | Live CLI type + resume per slot |
| `roles/_vendor/` | **LOCKED** role-pack (yaml + docs) — `sm update` |
| `roles/*.extend.yaml` | **USER** project POV — never overwritten |
| `runtime/` | Daemon jsonl state (inbox, checkback) |

**Seat files** (FOCUS/TASKS/REMINDER) live under `seats.root` in yaml — not deleted
by init; `sm seat init` creates missing files only.

```bash
sm init
sm roles status
sm roles migrate          # up to current role-pack
sm update                 # refresh _vendor + auto-migrate pack
```

See `roles/_vendor/docs/EXTEND.md` for locked sections.
