# seatmesh help

```text
help [cmd]
  Show this index, or usage for one command.
  Humans first: seatmesh help human   ← put an agent on a pane
  Agents: seatmesh agent help [cmd]
  Card:   seatmesh agent
```

- CLI: `seatmesh help --help`
- Agent: `seatmesh agent help help`
