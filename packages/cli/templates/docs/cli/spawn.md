# seatmesh spawn

```text
spawn <target> <agent|claude|opencode|kiro> [flags]
  Empty shell → agent CLI (preferred vocal). Same engine as switch.
  Replace live agent: switch. Resume configured: launch. See: help human
  Examples: spawn slot-1 opencode · spawn here agent · spawn secretary opencode-cpe --keep-resume
```

- CLI: `seatmesh spawn --help`
- Agent: `seatmesh agent help spawn`
