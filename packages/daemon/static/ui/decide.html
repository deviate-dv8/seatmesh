Decide (beta)

Agent notify yesno shows a toast with native Info / Yes / No buttons (Linux notify-send) and opens the browser decision card. Yes/No peer the reply seat as PRIORITY [operator-decide]. Raw /act/v1 URLs are not dumped in the toast (they are not clickable there).

  1. Agent: seatmesh agent notify yesno "<title>" "<body>"
  2. Toast: click Info → this UI’s decision card (/act/card/…)
  3. On the card (or toast): Yes / No
